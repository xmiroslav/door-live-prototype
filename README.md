# Door Live Prototype

Mobile browser prototype for door visualization. Open via HTTPS for camera permissions.

## Deploy
1. Create a **public** GitHub repository named `door-live-prototype`.
2. Upload `index.html` and `.github/workflows/pages.yml` to `main` (or push this folder with git).
3. In Settings → Pages → Build and deployment, select **GitHub Actions**.
4. Visit `https://YOUR_USERNAME.github.io/door-live-prototype/` after deployment succeeds.

Camera permissions may require opening the URL directly in Safari, rather than an in-app preview.
This prototype does not provide production-grade AR tracking.
